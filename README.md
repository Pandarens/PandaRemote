# 🐼 Panda Remote

Личный удалённый доступ к ПК и игровой стриминг **без IP-адресов, проброса портов и аккаунтов**.
Компьютер адресуется своим публичным ключом, поэтому динамический IP и NAT не мешают. Соединение P2P и зашифровано.
Всё своё: захват, кодирование, транспорт и клиент, без Sunshine/Moonlight.

Подробный дизайн: [docs/SDD.md](docs/SDD.md).

## Сборка

```bash
cargo build --release
```

Бинарник: `target/release/panda-rc.exe`.

## Как пользоваться

**На удалённом ПК** запустите `panda-rc.exe` → вкладка «Этот ПК» → «Разрешить доступ» → «Копировать» билет. Билет всегда виден на этой вкладке (кнопка с глазом показывает его целиком).
Или без окна: `panda-rc host`.

**На своём ПК** запустите `panda-rc.exe` → «Компьютеры» → «Добавить» → вставьте билет → «Подключиться» (или кнопка с геймпадом — игровой режим).
Зелёная точка у компьютера — он в сети (проверка раз в 20 секунд), серая — выключен или нет интернета.

Panda сама добавляется в автозапуск Windows и стартует свёрнутой; отключается галочкой на вкладке «Этот компьютер». Если там было включено «Разрешить подключения», после перезапуска хост включится снова.

**🎮 Игра**: кликните по картинке — мышь захватится окном (игры получают сырые движения и сканкоды). Отпустить мышь: `Ctrl+Alt+Shift+Q`. Полный экран: `F11`.

**Панель сеанса**: управление, перо, указка и «только просмотр» (глаз: экран виден, но мышь, клавиатура и геймпад не передаются). Кнопка «Ctrl+Alt+Del» нажимает это сочетание на удалённом ПК — Windows разрешает это только службе, поэтому на том ПК должна быть установлена служба Panda (при установке она включает политику `SoftwareSASGeneration` = 1, «службы»). Если у удалённого ПК несколько мониторов, кнопка с номером монитора переключает, какой показывать (сеанс быстро переподключается, PIN заново не спрашивается).

**Меню «Ещё» в сеансе**:
- **Отправить файл…** — или просто перетащите файлы на окно сеанса. Они сохраняются на удалённом ПК в «Загрузки\Panda» (до 4 ГБ на файл).
- **Сообщение на экран…** — текст на 6 секунд вверху экрана удалённого ПК.
- **Записать сеанс** — видео в том виде, в каком оно приходит, без перекодирования: H.264 в MP4, HEVC в файл `.hevc` (открывается в VLC). Файлы — в «Видео\Panda». На удалённом экране при начале записи появляется сообщение «Этот сеанс записывается».
- **Общий буфер обмена** (включён по умолчанию) — скопированный текст переходит в обе стороны.
- **Ctrl+Alt+Del**.

**Кодек** выбирается сам: HEVC, если на вашем ПК есть его декодер (бесплатные «Расширения для видео HEVC от производителя устройства» в Microsoft Store), иначе H.264. Что умеет ваш ПК: `panda-rc codecs`. AV1 пока не используется: на проверенном железе его кодировщик слишком медленный для живого видео.
Геймпад подключается к своему ПК как обычно; на удалённом ПК один раз установите драйвер [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases) — он создаёт виртуальный Xbox 360 контроллер. Вибрация из игры передаётся обратно на ваш геймпад.

**Чтобы ПК был доступен всегда** (экран блокировки, окна UAC, после перезагрузки до входа в систему), установите службу: `panda-rc.exe` → «Этот компьютер» → **«Установить службу…»** и подтвердите запрос Windows. Или в терминале администратора, указав полный путь:

```
.	arget
.\target\release\panda-rc.exe service install
```

Служба запускает свою копию программы из `C:\Program Files\PandaRC`, поэтому проект можно пересобирать, пока она работает. Чтобы обновить службу до новой версии, нажмите «Обновить службу…» (или снова `panda-rc service install`). Билет остаётся прежним. Удалить — кнопкой «Удалить службу…» или `panda-rc service uninstall`. Логи службы и журнал её подключений: `C:\ProgramData\PandaRC\logs` (читаются без прав администратора).
Если ПК был заблокирован, а вы вошли в него через Panda, то после отключения он снова заблокируется.
Когда удалённый ПК показывает экран блокировки, в окне сеанса появляется 🔒: клавиши передаются как физические, поэтому пароль набирается как на обычной клавиатуре, в раскладке экрана входа.
Пока служба работает, она и есть хост этого ПК; её журнал и билет видны во вкладке «Этот ПК». Служба работает на копии ваших файлов хоста, поэтому билет показывается без прав администратора; если копии нет (служба ставилась из другой учётной записи), нажмите «Показать билет…» и подтвердите запрос Windows.

Билет — это пароль. Если он утёк: «Сменить билет…» (или `panda-rc host --rotate-secret`).

**Билет для просмотра.** «Этот ПК» → «Билет для просмотра» → «Копировать» (или `panda-rc ticket --view`). По нему видно экран и можно рисовать указкой, но мышь, клавиатура, файлы и буфер обмена не работают — удобно показать экран другу. «Сменить билет…» меняет оба билета.

**Разбудить выключенный ПК.** Если ПК в режиме сна или выключен, а в его настройках (BIOS/UEFI и драйвере сетевой карты) включён Wake-on-LAN, его может разбудить другой ПК с Panda в той же домашней сети: меню «…» у компьютера → «Разбудить через «…»». Адрес сетевой карты Panda запоминает при подключении, поэтому хотя бы раз подключитесь к этому ПК, пока он включён. В терминале: `panda-rc wake <билет-соседа> <MAC>`.

**Трей.** Крестик прячет окно в трей: доступ к ПК и обновления продолжают работать. Вернуть окно — щелчок по значку панды, выйти — «Выход» в его меню. При автозапуске Panda стартует сразу в трей.

**PIN-код.** Чтобы одного билета было мало, задайте PIN: «Этот ПК» → «PIN-код при подключении» → «Задать…» (4–8 цифр), или `panda-rc pin 1234` (`panda-rc pin off` — убрать). При подключении Panda спросит PIN. После 5 неверных PIN-кодов подряд вход блокируется на 5 минут; все попытки видны в журнале. PIN хранится только в виде солёного хеша. Со службой изменение PIN подтверждается запросом Windows.
Журнал подключений: вкладка «Этот компьютер» или `panda-rc log`.

## Без серверов n0

ПК находят друг друга по ключу двумя независимыми путями: через справочник n0 и через Mainline DHT — распределённую сеть BitTorrent, у которой нет владельца и серверов. Если n0 недоступен, работает DHT (первая публикация после запуска занимает до минуты).

Если прямое соединение не получается (оба ПК за «строгим» NAT), трафик идёт через relay-сервер; по умолчанию это серверы n0. Свой relay — на любом сервере с белым IP и доменом:

```
cargo install iroh-relay
iroh-relay --config-path relay.toml
```

(настройка TLS — в [документации iroh-relay](https://docs.rs/iroh-relay)). Затем на хосте, в терминале администратора, если стоит служба:

```
panda-rc relay https://relay.example.com
```

Адрес relay публикуется вместе с адресом ПК, поэтому на клиентах ничего настраивать не нужно. Вернуть серверы n0: `panda-rc relay off`.

## Обновления

Panda проверяет [выпуски на GitHub](https://github.com/Pandarens/PandaRemote/releases) при запуске, раз в 6 часов и по кнопке «Проверить» на вкладке «Этот ПК». Новая версия скачивается, проверяется её подпись, и она ставится при перезапуске, по кнопке «Обновить сейчас» или сама — когда нет активного сеанса. Служба обновляется сама, без участия пользователя: через 30 секунд после запуска, раз в 6 часов и когда в программе нажимают «Проверить» (программа будит службу). Версия службы и что делает её обновлятор видны на вкладке «Этот ПК» под версией программы (файл `C:\ProgramData\PandaRC\logs\service-update.json`). Неподписанные файлы не устанавливаются.

Выпуск: поднять `version` в `Cargo.toml`, затем `git tag vX.Y.Z && git push --tags` — GitHub Actions соберёт, подпишет ключом из секрета `PANDA_SIGNING_KEY` и опубликует. Первый выпуск — [v0.2.0](https://github.com/Pandarens/PandaRemote/releases/tag/v0.2.0).

Версия 0.4.0 меняет протокол (кодек, файлы, буфер обмена, билет для просмотра): оба компьютера должны быть 0.4.0 или новее, иначе подключение отклоняется с «несовместимая версия протокола». Обновления ставятся сами, так что это нужно только если какой-то ПК долго был выключен.

## CLI

```
panda-rc                             GUI
panda-rc host                        хост без окна
panda-rc service install|uninstall|status   служба Windows (от администратора)
panda-rc ticket [--view]             показать билет (--view — билет для просмотра)
panda-rc pin <PIN|off>               PIN-код поверх билета (4–8 цифр) или убрать
panda-rc relay <URL|off>             свой relay-сервер вместо серверов n0
panda-rc connect <ticket> [--game]   окно сеанса (рабочий стол / игра)
panda-rc log                         журнал подключений
panda-rc ping <ticket>               в сети ли компьютер
panda-rc wake <ticket> <MAC>         разбудить ПК через другой ПК с Panda в той же сети
panda-rc codecs                      какие кодеки этот ПК кодирует и декодирует
panda-rc update                      проверить и установить обновление
panda-rc probe <ticket> [--game] [--pin PIN] [--monitor N] [--codec C]   диагностика: fps, потери, кадр в PNG
```
